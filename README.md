# Shadow Routes: Mapping the Nexus of Crime and Migration in Mexico

**Shadow Routes** explores the spatial and temporal relationships between organized crime and internal migration in Mexico. The project integrates official crime statistics, displacement reports, and migration records to identify how violence and criminal economies shape mobility patterns within the country.

This repository contains the analysis scripts, notebooks, and documentation that support the empirical component of the project.

---

## Project Goals

- Model the spatial diffusion of organized crime and violence
- Analyze internal migration and forced displacement
- Integrate spatial and temporal data sources
- Develop ABM models 
- Support policy and academic research to provide open, transparent analytical tools for understanding violence-driven migration in Mexico.

---

## Data Layout & Policy

All data are **external** to this repository and are not distributed here due to licensing restrictions.

---

## Reproducibility

- All dependencies are pinned in poetry.lock.
- Randomness in models should be seeded and logged.
- Notebooks include descriptive headers outlining datasets, methods, and outputs.
- Every figure or table generated for analysis can be reproduced by rerunning the corresponding notebook.
